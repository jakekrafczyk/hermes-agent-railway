# Task File Format Specification

## research_findings
Sections:
- ## Summary (1-2 paragraph synthesis)
- ## Key Findings (numbered list with sources)
- ## Methodology (tools used, search parameters)
- ## Sources (URLs with access dates)
- ## Limitations & Gaps (what wasn't found)
- ## Recommended Follow-up (if any)

## scraped_data
Sections:
- ## Data Summary
- ## Raw Data (formatted extraction)
- ## Source URLs
- ## Completeness Check

## analysis
Sections:
- ## Executive Summary
- ## Analysis
- ## Recommendations
- ## Risks & Assumptions
- ## Supporting Data

## error_state
Sections:
- ## Error Details
- ## Context (what was being attempted)
- ## Fix Hint (if known)
- ## Stack Trace (if applicable)

## report
Sections:
- ## Executive Summary
- ## Full Report
- ## Key Metrics
- ## Conclusions
