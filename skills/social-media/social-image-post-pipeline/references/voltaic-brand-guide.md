# Voltaic Marketing — Brand Design Guide

Extracted from voltaicmarketing.com (June 2026). Use these values for any Voltaic-branded graphics.

## Color Palette

| Role | Hex | RGB | Usage |
|---|---|---|---|
| Dark background | #1A1A1A | rgb(26, 26, 26) | Hero sections, alternating dark sections, footer |
| Light background | #F5F2EE | rgb(245, 242, 238) | Alternating light sections, cards |
| Amber accent | #C4881A | rgb(196, 136, 26) | Section labels, accent elements, highlights |
| Cream heading (on dark) | #F0EDE8 | rgb(240, 237, 232) | Headings on dark backgrounds |
| Body text (on light) | #333333 | rgb(51, 51, 51) | Paragraph text on light backgrounds |
| Link blue (on light) | #0066CC | rgb(0, 102, 204) | Links and CTAs on light sections |
| Button text (on dark) | #F0EDE8 | rgb(240, 237, 232) | CTA button text on dark sections |

## Typography

| Element | Font | Weight |
|---|---|---|
| Headings | DM Sans, sans-serif | 500-700 |
| Body | Arial, sans-serif | 400 |
| CTAs / Labels | DM Sans, sans-serif | 500-600 |

## Design System

- **Section pattern:** Alternating dark (#1A1A1A) and light (#F5F2EE) backgrounds
- **Cards:** Rounded rectangles, light background on dark sections, subtle borders
- **Buttons:** Clean, minimal. Either transparent with cream text (on dark) or blue links (on light)
- **Overall aesthetic:** Minimal, high contrast, warm-neutral palette. No neon, no electric colors, no gradients. Professional but approachable — "a mechanic's shop, not a corporate lobby."
- **Logo:** Stylized swirling sun/energy icon with warm-to-cool gradient (yellow → green → teal → blue). Text in dark gray sans-serif with subtle 3D/shadow effect.

## For Social Graphics

When generating Voltaic social media graphics:
- Use #1A1A1A or #F5F2EE as the dominant background
- Amber (#C4881A) for accent elements only (underline, small highlight, section label)
- Cream (#F0EDE8) for headline text on dark backgrounds
- DM Sans for any text that's part of the graphic design
- Keep it minimal. Breathing room is part of the brand.
- No cyan, no navy blue, no electric colors, no gradients

## Image Design Rules

**All image content must be purely educational.** The image is where the audience learns something. The caption is where the optional invitation lives.

- No CTAs, buttons, or action language in the image ("Book now," "Learn more," "Sign up," "Find your leak")
- No pushy elements: badges, labels, urgency markers, "LIMITED TIME," diagnostic bubbles
- Exception: small, subtle brand mark (logo icon) in one corner, watermarked style, 80% opacity maximum
- Focus on making one concept intuitively clear at a glance
- If a random viewer would describe the image as "an ad," it's too pushy
