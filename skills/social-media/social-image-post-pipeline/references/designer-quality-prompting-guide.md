# Designer-Quality Social Media Graphics — Prompting Guide

Techniques for producing AI-generated social media graphics that look designed by a thoughtful human designer, not generated by AI. Built from design principles research (Gestalt, visual hierarchy, F/Z-patterns, typography) and tested FAL API workflows.

## The Two-Stage Pipeline

```
Stage 1: Ideogram 3.0 → base graphic with text (best text rendering)
Stage 2: FLUX.1 [dev] Image-to-Image → refinement (sharpens, cleans, harmonizes)
```

**Why two stages:** Ideogram has the best text rendering but produces slight inconsistencies (shadows, edges, spacing). FLUX image-to-image at low strength refines without destroying layout. Combined, they produce designer-quality output.

### Stage 1 — Ideogram Prompt Structure

Use the **Creative Brief Format** (tested by CrePal at 65% usable-first-try rate):

```
[Subject — what is this?] [Style — visual vibe] [Text — exact wording + casing + placement in quotes] [Composition — layout description] [Constraints — color limits, aspect ratio]
```

### Stage 2 — FLUX Refinement

```bash
curl -X POST "https://queue.fal.run/fal-ai/flux/dev/image-to-image" \
  -H "Authorization: Key $FAL_KEY" \
  -H "Content-Type: application/json" \
  -d '{"image_url":"<stage1_output>","prompt":"Same exact layout and design. [describe the desired look with refinement keywords: clean, sharp, professional, symmetrical, consistent, crisp typography, immaculate spacing]. No artifacts.","strength":0.2,"num_inference_steps":28}'
```

**Strength guide:**
- `0.15-0.20`: Subtle cleanup — sharpens edges, unifies colors, fixes minor inconsistencies
- `0.20-0.30`: Moderate refinement — cleans shadows, improves symmetry, harmonizes spacing
- `0.40+`: Significant transformation — use only if the base needs major rework

## Design Principles for Prompting

### Visual Hierarchy (Z-Pattern for Social Cards)

Social media graphics have seconds to capture attention. The eye moves in a Z-pattern:

1. **Top-left → Top-right**: Headline must be in the top third. 5-6 words ideal.
2. **Diagonal down-left**: Secondary information (cards, subtext) in the middle third.
3. **Bottom-right**: Brand mark, CTA, or closing element.

**Prompting this:** "Headline centered in top third. Three cards in bottom two-thirds. Brand mark in bottom right corner."

### The 12 Design Principles (Apply These to Prompts)

| Principle | How to Prompt It |
|---|---|
| **Contrast** | "dark charcoal background, bright cream text, amber accents" |
| **Balance** | "perfectly centered, symmetrical layout, equal spacing" |
| **Repetition** | "three identical cards, same dimensions, same corner radius, same style" |
| **Proportion** | "headline large and dominant, cards smaller and subordinate" |
| **White Space** | "generous margins, breathing room, clean minimal aesthetic" |
| **Unity** | "3 colors maximum, consistent typography throughout" |
| **Rhythm** | "evenly spaced, regular intervals, consistent padding" |

### Typography Rules

- Headlines: 5-6 words ideal. Bold. Sans-serif. Placed in top third.
- Card labels: 1-3 words max. Bold. Same font family as headline.
- Never put body text in the image. That's what captions are for.
- Text contrast: light text on dark background or dark text on light background. Never medium-on-medium.

### Color Palette Rules

- Limit to 3-4 named colors
- One dominant background color
- One accent color (used sparingly — 5-10% of the design)
- The 60-30-10 rule: 60% dominant, 30% secondary, 10% accent
- Never use: neon colors, gradients, more than 4 colors

### Consistency — The #1 AI Tell

Inconsistent shadows, slightly different card sizes, varying corner radii — these are what make AI graphics feel "off." Fix with:

1. **Explicit symmetry language**: "identical," "same dimensions," "matching," "uniform," "equal spacing"
2. **FLUX refinement pass**: smooths out inconsistencies
3. **Negative prompt**: "drop shadows, gradients, bevels, inconsistent sizing, varying corners"

## Composable Design with FAL APIs

### Logo Placement — THE CORE RULE

**Never ask any AI model to generate a logo.** Models hallucinate approximations that look similar but aren't your actual brand mark. Always:

1. Generate the clean graphic (Ideogram → FLUX refine). Do NOT mention a logo in any prompt.
2. Composite the official logo file via Pillow script after generation.

See the `social-image-post-pipeline` SKILL.md "Logo Footer Compositing" section for the exact script.

### Text Over Photo (Image-to-Image Compositing)

Use `fal-ai/flux/dev/image-to-image`:

```bash
curl -X POST "https://queue.fal.run/fal-ai/flux/dev/image-to-image" \
  -H "Authorization: Key $FAL_KEY" \
  -d '{"image_url":"<photo_url>","prompt":"Same photo with educational text overlay at bottom: \"YOUR HEADLINE HERE\" in white bold sans-serif on semi-transparent dark bar. Rest of photo unchanged and sharp.","strength":0.25,"num_inference_steps":30}'
```

**Key:** Low strength (0.2-0.3) preserves the original photo while adding text or overlays. The prompt MUST say "rest of photo unchanged."

### Inpainting for Spot Edits

Use `fal-ai/flux-general/inpainting` to modify specific regions:
- Upload base image + mask image (white = edit area, black = preserve)
- Prompt describes what to put in the masked area
- Everything outside the mask stays pixel-perfect

### Uploading Images for FAL API

FAL accepts URLs. To use a local file:
1. Upload to a public URL (S3, Imgur, CDN)  
2. Or: upload via FAL Assets API: `POST https://rest.fal.ai/assets/upload`

## Checklist for Each Generation

Before Stage 1 (Ideogram):
- [ ] Design preset selected
- [ ] Magic Prompt OFF
- [ ] Text ≤6 words per string, in quotes, placed early in prompt
- [ ] 5-6 word headline in top third
- [ ] 3 colors maximum named
- [ ] Explicit symmetry language ("identical," "equal spacing," "uniform")
- [ ] Z-pattern layout described (headline top, cards middle, brand mark bottom-right)
- [ ] Affirmative descriptions only (never "no shadows," use "flat design, clean edges")
- [ ] Generous white space described

Before Stage 2 (FLUX refinement):
- [ ] Strength 0.15-0.25 for cleanup
- [ ] Prompt starts with "Same exact layout and design"
- [ ] Refinement keywords: clean, sharp, professional, symmetrical, crisp, immaculate, no artifacts
